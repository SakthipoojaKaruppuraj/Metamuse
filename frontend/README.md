# MetaMuse Frontend

Please refer to the root [README.md](../README.md) for full project architecture, setup instructions, contract details, and automated test instructions.

## Quick Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run automated tests
npx tsx --test test/backend-services.test.ts test/e2e-integration.test.ts test/context-explanation.test.ts

# Production build
npm run build
```
